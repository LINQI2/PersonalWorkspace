## 八类问题的复现与处理

| 问题 | 修复前真实路径 / 证据 | V1.7.2 处理与验证 |
| --- | --- | --- |
| 置顶不明显 | 知识库单项操作只有空文本图标，pressed 状态没有明确视觉；文档操作后阅读记录没有重读 | 共用 Pin 按钮常态显示「置顶/已置顶」，选中颜色/边框/图标明确。列表、网格、首页、详情同 API；预览/文档/独立知识详情操作后重新读取。三种排序仍优先置顶 |
| 设置误报 | 当前正式配置零修改关闭未复现；冻结基线将状态 model 设为空，打开分类后零修改关闭确实弹出 AI 警告。加载时使用候选默认模型，脏判定却对比空 model | 配置加载与保存统一基准模型。未配置、空模型、浏览/切分区零修改关闭无警告；输入虚构密钥/更换 Provider 才提示。分类与备份恢复准备状态有自己的关闭确认，不冒充 AI 提示 |
| 设置混杂 | 总入口卡片再打开旧设置弹窗；备份与草稿仍同区 | 顶栏/侧栏直接进入同一设置弹窗，六个二级分区；分类加号直接相应分类。AI 面板保持挂载以保留未提交输入，但仅显示当前分区。窄屏横向分区导航；导入/回收站在数据区，草稿单独管理 |
| 筛选二次操作 | 点专题 summary 后出现原生 select，需再点；再点标签同时保留两个 details open | 单一受控展开状态，维度按钮直接显示选项按钮；切换互斥、外点/Escape 关闭。生效值独立，组合条件、单项移除、全部重置与空结果反馈保留 |
| 文档弹层遮挡 | 1366×768 关联/AI 弹窗 top≈31px，嵌套阅读器 z25，固定顶栏 z30 实际拦截关闭点击 | Dialog portal 到 body 顶层 z100，视口内高度、固定头与内部滚动。关联、上下文 AI、收纳、历史、编辑共用。最上层 Escape 不关闭背后阅读器；嵌套滚动锁按引用计数释放。桌面/390px 检查关闭命中与底部可达 |
| 侧栏树不清 | 分组没有独立箭头，summary 混合折叠与加号；无选中/数量。长名字还可能撑宽结构网格 | 独立分组箭头/标题/加号，名称只导航，父节点箭头只折叠。树节点统一高/缩进/数量/焦点，长名省略并有完整 title。当前选中同步真实筛选。桌面整体收起保留四入口图标与提示，窄屏使用原展开按钮 |
| 管理领域扭曲 | 表单标签挤在一起；节点按名字平铺，无父子层级 | 与侧栏复用 DomainTree；表单栅格、长名省略、子级缩进、选中项及新增子领域。改名/移动/顺序保存复用现有接口。父选项排除自己和后代；服务端仍防循环。非空删除禁用并说明先调整归属/子领域；规则/视图引用仍由服务端拒绝 |
| 概念与实际不符 | V1.7.1 设计记录对「落实」描述过宽，尤其正文选段批注与 AI 工作台布局 | 下表逐项说明真实能力及缺口；没有新增批注模型、自动抓取或第二 AI 工作台来凑图 |

## 逐页面落实清单

状态使用：**符合**=已实现且符合交互；**等效**=操作存在但采用不同布局；**不一致**=已实现但仍与图不同；**缺失**=尚未实现；**条件不足**=当前数据或技术条件不支持。

| 页面 / 对照 | 交互承诺与实际状态 | 剩余差异、成本与建议 |
| --- | --- | --- |
| 首页 / 文字 | **符合**：极简快速记录、真实待处理摘要、最近内容、单条操作与全局新建。**等效**：继续阅读为当前浏览器最近真实 ID，不虚构进度 | **条件不足**：没有独立首页参考图、跨设备阅读进度数据。继续阅读不追踪精确阅读百分比；无需补造统计 |
| 收集箱 / 文字 | **符合**：快速保存、待处理队列、查看/完成/稍后/编辑/回收；同 ID，完成不复制正文。复杂导入独立 | **等效**：分类通过原编辑器调整，不在每条队列铺完整多选表单。没有后台自动保存快速输入，明确文字说明 |
| 知识库 / 01 | **符合**：领域树/专题、四类类型切换、全文与章节检索、组合筛选、有效条件、列表/网格、置顶独立排序、预览/直接阅读、多选次级入口 | **等效**：主要领域由侧栏进入；类型用 tabs。**不一致**：卡片行高随用途/领域信息变化，与示意的完全等高短行不同；保留真实元数据，无必要为像素对齐隐藏正文摘要 |
| 普通笔记 / 02 | **符合**：正文优先、短普通笔记在当前阅读器编辑、原文历史、来源、关联、上下文 AI、软删除保护。**等效**：辅助内容折叠区而非常驻右栏 | **缺失**：选中正文后浮动「批注/引用/询问 AI」及独立逐段批注对象。当前整篇编辑、知识关联依据和整篇上下文问答不能冒充逐段批注。成本高：锚点漂移、历史和数据模型需单独设计/验收；本轮不新增 |
| 网站收藏 / 03 | **符合**：原网址快捷打开、真实来源平台、用户描述/摘录与来源快照、个人富文本批注、关联和历史。**等效**：来源折叠而非固定右栏 | **条件不足**：未抓取网页正文，来源标题不能当完整已读证据。示意封面与原文内容不是必须生成；保留已有材料不要求网络可用 |
| 工具 / 04 | **符合**：类型、用途、图标/上传图、可选网址、个人经验、相关知识、单项管理，无网址可保存。**等效**：相关工具使用有类型的真实关系，预览可编辑入口复用安全编辑器 | **缺失**：独立多链接「常用链接」结构化字段；可以在已有富文本经验里放多个安全链接。成本低到中，但新字段/迁移不属于本轮基础修复；现有链接等效使用即可。桌面软件不会自动启动 |
| 综合文档 / 05 | **符合**：明确章节树、稳定 UUID、折叠/定位/手动顺序、阅读/整理、大纲与正文、来源/历史、知识关联、收纳原记录、上下文 AI | **等效**：辅助 tabs 与顶层弹窗代替默认三栏，窄屏单栏。**缺失**：逐段批注同笔记；不能声称辅助 tab 就是逐段选区操作 |
| AI 助手 / 06 | **符合**：先检索/选证据、真实引用、性质区分、规模/费用确认、取消、结构审核/历史、跨范围整合，人工采用且版本重验 | **等效**：三项顶部任务 tabs，关系发现在内容关联面板，历史独立弹窗。**不一致**：未采用概念图五项左任务栏/聊天式追问气泡。成本中：只需导航整合但应单独决定是否增加固定任务；本轮不造第二审核系统。真实云端质量 **条件不足**（未授权调用） |
| 知识探索 / 07 | **符合**：真实节点/方向、一层/两层、类型/候选过滤、键盘节点、列表替代、真实数量/40节点80边限制、内容与章节跳转 | **等效**：可关闭弹窗与原生 SVG 局部布局，不是独立常驻全页图工作台；示意节点/连线是样例，无需复制虚构内容 |
| 设置 / 08 | **符合**：AI 服务、分类、数据、草稿、本地运行、外观独立入口，导入/回收、正常停止、安全密钥/用量保留；加号准确定位。**等效**：共用二级导航弹窗而非独立路由 | **不一致**：普通分类界面没有独立合并向导；已有 AI 结构审核支持合并并保护引用，不等于设置中免 AI 的手工合并。成本中，需差异确认与历史接口；本轮保留现有安全能力。不存在自动保存设置，不补虚假开关 |
| 全局 / 00、文字 | **符合**：四项顶侧导航同步、统一操作、列表返回保留查询/筛选/排序/浏览位置、删除回收、真实来源与 AI 人工审核、安全导入 v1/v2 | **等效**：保留青绿色已有视觉而非蓝色新品牌。旧保存筛选仅兼容入口，没有新增「常用视图」分组 |
