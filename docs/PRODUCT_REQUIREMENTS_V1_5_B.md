## 阅读与组织

- 有混合页面的目录默认页面优先；没有页面时仍显示独立记录。“查看所有知识点”和搜索始终可找到独立/从属点，隐藏展示不改变数据。
- 明确的知识点父级可以是页面或章节，最多8层、无环、必须最终到达 page。目录、普通资源引用与 parent 候选关系不构成归属。
- 阅读页：概览、正文、大纲、逐章节展开/折叠与定位；章节正文按需加载，来源/状态/优先级按需查看。整理模式收纳、移出、改父级、上下排序、复用编辑器、选择整合/归档。
- 收纳只写父级与顺序，稳定 ID、正文、日期、来源和原目录不复制/删除。跨页移动父章节后其后代跟随；有后代的节点不能移出至无所属页或直接删除，需先调整子章节。
- 已有导入原包的显式 parent 或已有 parent 关系仅作为待确认的收纳建议。不根据同目录自动改真实知识。
- 知识编辑保存前保留旧标题/HTML，可查看历史并放入编辑器再保存；原来源快照不改。排序/归属不是正文历史。

## 导入与 AI

交换格式继续 personal-knowledge-exchange v1。新审核显示最终层级、允许改 parent；只在用户确认写入时建立实际结构。取消/部分选择/父级缺失或循环会安全拒绝整批，不留半批。旧无 page 根的 parent 仍为关系建议，默认独立保留。

用户在整理模式选2～10条知识，先看输入字符/Token粗估及所选Provider参考输入费，再主动确认生成。只发送所选标题、简介、正文、来源性质与状态，不读取链接或全库。输入最多12000字符，超限明确要求用户缩小选中范围/人工分批，不自动拆分或截断。

结果含保留独立条目、候选章节、六类关系、逐字依据、待验证和阅读顺序。ID限定所选记录，有具体正文才能被章节引用；关系两端的引文须逐字属于本次对应文本。生成完成/采用前重验来源快照。章节/关系说明/类型/顺序可编辑，逐项选择/拒绝。采用章节另存待验证 AI 推断，原文不覆盖；关系仍为 candidate，related 不写成强关系。阅读顺序仅能显式调整当前页面直属章节。

选中集本地文本标准化/同名候选不调用模型；相同资料快照、Provider/模型/配置的成功方案在服务内存缓存15分钟（最多8份）。过期、重启、源文本/版本变化失效；缓存命中明确标识本次未调用。审核也最多8份/15分钟，独立于正式笔记/专题/知识草稿，未采用方案不持久化。
