- professional-knowledge-v1 JSON导入：512KiB/100条、严格字段/来源/专业领域ID验证、短期预览、人工选择、同名明确另存、变化后拒绝迟到提交、事务创建review记录；原始包、来源和导入映射使用既有知识追溯表保存。旧个人导入入口拒绝该格式。
- 首批12张与扩展28张分批预览，合计35目录、40非空卡、40来源和32条candidate关联。稳定seed_key及事务保证重复运行不覆盖人工修改。B级清单未生成空白记录。
- 内部AI个人/专业/两者检索，英文别名、来源URL、入口默认空间及选中资料空间检查。旧个人结构管理与整合拒绝改写专业结构。
- 外部GET四能力和只读CLI；PW_KNOWLEDGE_URL可指定显式127.0.0.1测试端口。未新增远程监听、CORS、账户或MCP传输；HTTP/CLI是规格允许的接入方式。

## 空间边界审计

个人默认列表/回收站/统计、旧知识列表、动态专题、导入去重和AI候选均排除专业记录。普通编辑器、批量个人分类、个人专题加入、章节移动/建议、旧AI结构管理/知识整合不能改写或收纳专业记录。关系候选默认使用中心对象所属空间，用户勾选后才跨空间检索；已明确建立的跨空间关系仍可读取。稳定ID详情返回space，旧阅读/编辑/引用入口将专业内容路由到专业模块。阅读引用目标默认个人，原有明确UUID引用保留。

这是现有同一用户、本机回环服务的空间边界，不是新增的账户权限系统。CLI只提供GET能力；网站管理写入继续受Host/Origin/X-PK-Request/session/维护门保护。
