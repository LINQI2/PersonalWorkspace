# V1.1 产品与体验优化范围

本文件记录 2026-10-12 用户授权的 V1.1 优化及落地取舍。V1 的基础功能和数据保护约束继续遵循 PRODUCT_REQUIREMENTS_V1.md；未修改原规格。顺序为视觉与浏览体验 → 收藏效率 → 笔记体验 → 必要稳定性。最终停在 V1.1，不自动开发后续版本。

| 范围 | V1.1 交付行为 |
|---|---|
| 视觉 | 中性色与绿色强调色，统一控件/选中/焦点/反馈，领域名称生成稳定色调和图标的默认封面；网格封面 2:1；响应式和深色主题 |
| 浏览 | 保留统一收藏/原创笔记、待整理、搜索、多分类模型；网格/列表切换；五种排序；领域/标签/专题组合筛选及清除；直接置顶 |
| 添加 | 网址优先聚焦；当前筛选默认选中；本地重复检测并查看已有收藏；允许明确保留重复；表单内新建分类 |
| 最近使用 | 从已保存条目关联的最新 updated_at 推导，最多六项；优先排列并标记，不新增独立历史表 |
| 批量 | 仅当前页 24 条；添加一种分类关联、置顶/取消置顶、确认删除；数据库事务校验全部选择；不替换分类，不改写正文 |
| 笔记 | 格式状态、撤销/重做状态、图片引用移除、链接地址面板、字数、长文阅读排版；不批量变换已有正文 |
| 草稿 | 服务端本地文件持久化，编辑停顿 650ms 自动保存；关闭前确认并刷入草稿；重新打开恢复/放弃；条目变化提示；设置内确认清理 |
| 偏好 | 网格/列表与排序写入 data/workspace.json；主题仍为浏览器偏好 |
| 数据保护 | schema 仍为 1，无库重建/就地正文改写；工作文件原子替换；ZIP 包含草稿/偏好；支持旧 V1 包；恢复中断回滚同组文件；单目录实例锁 |
| 交付 | 构建、六项集成测试、V1/V1.1 浏览器交互、Windows 启动、实际生产只读检查、截图和开发文档、Git 本地提交 |

重复判断只标准化 URL 解析中的主机大小写、默认端口、根路径斜杠并忽略 fragment；保留 query，不主动删跟踪参数，不改写用户保存的 URL。http 与 https 不合并。

每个已保存条目一份草稿，新增共用一份；50 份/10 MB 上限。已删除条目的草稿不自动清理，可备份、查看名称和明确丢弃；本轮未加入草稿独立发布入口。突然终止仍可能损失尚未自动保存的最后输入，界面显示真实保存状态。

复用表现正常的 V1 SQLite、富文本格式、本地附件、分类关系、搜索分页、ZIP 安全恢复与启动脚本。前端按首页/编辑表单/富文本/设置/共用组件拆分，新增后端模块均有明确职责。

不包含自动同步抖音/知乎、AI API、自动抓取、云部署、账号、分享、知识图谱或其他 V2 功能。验收证据及未验证事项见 TESTING.md。
