# V1.7.3 内容阅读工作台

日期：2026-10-15。基线 `57eef955d97adbb6b9fbb7bc4aed6d9c6de3e6b4`。沿用 React/Express/SQLite/Tiptap，无新依赖、SQL 迁移或第二内容模型，schema9 不变。

## 最终浏览路径

| 内容 | 点击列表/首页/收集箱主体 | 其他明确操作 |
| --- | --- | --- |
| 普通笔记 | 本地快速预览 | 完整阅读、编辑；短笔记沿用原位编辑与原草稿 |
| 网站/视频收藏 | 本地快速预览 | 完整阅读、编辑、独立打开原网站；仅展示已保存摘要与批注 |
| 工具 | 本地快速预览 | 完整阅读、编辑、独立访问官网；无 URL 工具仍可用 |
| 综合文档 | 直接完整阅读 | 单独预览按钮查看概要，阅读/整理模式切换 |

预览统一展示类型、标题、摘要、领域/标签、已有来源追溯、个人正文和关联。正文有高度限制与内部滚动。预览不会抓取来源网站或把网址当作已读正文。独立知识点仍可完整阅读；属于文档的知识块仍定位所属文档和稳定章节 ID。

## 固定操作区与双侧栏

- 阅读器顶部固定返回、可省略并悬停查看的完整标题、适用模式/大纲、编辑、辅助信息、常态置顶及更多菜单。回收站状态可见且不能直接编辑。全局导航仍可访问。
- 固定栏通过 ResizeObserver 测量实际换行高度；章节点击根据实际固定栏底部计算偏移，避免叠加滚动留白。滚动追踪同步当前大纲章节。
- 大纲按真实父子关系缩进、分支展开/收起、整体收起；正文利用释放空间。不会改名、重排或重建章节 UUID。无章节时不留空大纲。
- 右侧统一 ReaderPanels，来源与历史 / 知识关联 / 上下文 AI 三个标签可切换，关闭按钮或 Escape 收起，长内容内部滚动。辅助按钮只影响当前内容实例。
- ≥1700px 可同时保留大纲与右面板；中等桌面优先正文，打开右面板时暂隐大纲；≤1450px 右面板采用视口内覆盖抽屉。≤760px 大纲为按需浮层，定位后收起，全局侧栏默认收起。窄屏固定栏允许换行。
- 嵌套 Dialog 仍走顶层 portal、滚动锁和最上层 Escape；关闭 AI/关联弹窗不会同时关闭背后阅读器。面板关闭后空间归还正文。

## 复用业务与审核边界

来源复用 ContentProvenance、知识来源快照、实际日期与性质、正文版本和知识历史。保存网址明确不代表已获取/验证原文。关联复用 RelatedPanel 的方向、依据、人工创建与 AI 候选审核。上下文 AI 复用 ContextAssistant：可选当前文档或实际章节，再在已有证据/费用确认界面主动生成。没有创建新的 AI 引擎、自动请求或正式知识写入路径。

整理模式沿用原章节管理：每行紧凑显示层级、标题、状态和选择框，仅选中的“管理章节”展开移动/父级/编辑等控件；保留收纳、排序、移出、归档和整合审核。整理时隐藏长篇文档正文，减少到达管理区所需滚动。

## 导航与状态恢复

- 同一会话保存知识库查询、类型、专题/标签/来源/状态、排序、页码、列表滚动位置；网格/列表沿用已有偏好。
- 显式“返回列表”回到进入阅读的根页面；浏览器后退遵守预览→完整阅读的历史层级。新领域/专题导航使用新的意图标识，清除旧页码/滚动/隐含来源状态，不覆盖新选择。
- 异步打开/预览响应绑定发起时的导航状态，快速后退后迟到响应不能重新打开旧内容；测试特意延迟详情响应覆盖此竞态。
- 每个文档的大纲开合、分支折叠、已展开章节、当前章节与辅助标签使用 sessionStorage，保存的是 UI 元数据，章节正文仍从数据库读取。
- 普通/知识编辑器的浏览器后退加入实际 dirty/busy 检查；干净编辑不误报，未保存编辑确认后才能关闭。原编辑器草稿、专题关闭保护及历史恢复语义保留。
- 这些状态不承诺跨浏览器或跨设备同步，也不新增阅读百分比或虚构进度。

## 快速记录保护

快速记录共享一个客户端状态，首页、收集箱及全局新建不会各自覆盖输入。400ms 防抖写入现有 workspace 的独立 `drafts.quick`，与普通 `drafts.new`、工具、知识/专题及 AI 草稿隔离。专用 `/api/quick-draft` 采用 UUID 修订令牌；过期写入/删除返回冲突，通用草稿 API 不允许绕过版本校验。

为保护防抖尚未发出的文字，浏览器 localStorage 存储按数据目录和窗口标识隔离的恢复副本（仅快速记录内容，绝无 API Key）。刷新恢复，多窗口差异需要明确选择“载入服务端草稿”或“保留当前输入”，不会静默覆盖。浏览器存储不可用、网络错误、冲突或保存失败均可见；没有后台无限重试。

只有用户点击保存才创建正式记录；成功后按修订令牌清除对应草稿及相同恢复副本，不删除其他窗口不同文字。创建成功而清草稿失败时明确提示，不自动重复创建。请求返回不确定时应先检查收集箱再手动重试。编辑关闭仅在真实字段修改时确认，临时草稿仍保留。

服务端已保护草稿进入现有 ZIP 并可恢复，最新尚未同步的浏览器副本不在 ZIP；需要同一浏览器配置且未清除存储才能恢复该副本。旧 ZIP 无 quick 键仍兼容；含新键的 workspace 应使用 V1.7.3 或更高版本打开，不直接降级旧运行时。SQL schema 不变。

## 差异与后续边界

双侧栏根据宽度互斥/覆盖是正文空间优先的等效实现，不保证任意窄屏并排三栏。普通笔记没有新增正文标题提取大纲；综合文档的既有章节树完整支持。列表摘要默认三行，缺少摘要时省略，不用长文填充。内部领域树仍保留兼容入口，默认使用全局领域导航，未删除分类能力。

未新增逐段批注、复杂选区锚点、自动网页/视频正文、全局知识图谱、AI 会话历史或全库自动整合。多结构化工具链接等仍是后续候选。

DeepSeek 整合超时归类为 **疑似上游服务异常，待恢复后复测**；本轮没有调整超时、Provider、模型或接口架构。AI 仅模拟响应回归；未用真实 Key、未调用付费 API。用户最终使用验收、真实云端质量和 Windows 整机重启未验证。本轮停在 V1.7.3，不自动进入 V1.8。
