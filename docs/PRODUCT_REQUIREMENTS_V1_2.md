# 个人知识收藏馆 V1.2 需求与交付范围

依据用户 2026-10-12 V1.2 授权与 2026-10-13 中断恢复指令；V1/V1.1 需求继续作为基础。保留中断前实现，不整体重构。停止在 V1.2 验收点。

- 在添加/编辑收藏内按已有标题、简介、正文生成标题、摘要、已有领域/标签/有依据的专题、新标签和分类依据。不能根据 URL 猜测真实内容，资料不足显示 insufficient。
- 富文本工具栏整理笔记：结构、要点、标题、摘要及表达修正，先预览；人工采用才更新表单。原 HTML 在前，整理稿追加在后，保护事实、数据、链接和图片。
- 同一审核区支持接受全部、选部分、手动修改、取消拒绝。现有分类绑定 ID；新标签明确确认创建。AI 永不直接修改正式条目。
- 云端 Provider 服务端调用，安全环境变量密钥、固定 HTTPS Endpoint、真实 JSON Schema 与服务端复核。给未来本地 Provider 留契约，不下载/运行本地模型。
- AI 可选，缺密钥、网络错误、超时、取消不会破坏普通功能。手动触发、输入与 Token/并发/小时次数限制，无后台重试，用量记录和参考费用。
- 不上传其他私人收藏正文/整个库，不自动抓取，不引入账号、云部署、分享、向量库或任务队列。
- 可选批量 AI 优先级最低；本轮不实现，多条条目继续使用 V1.1 人工批量分类。
- 修复 PID 存活不等于原服务身份的启动缺陷：新锁比较创建时间/可执行路径，明确陈旧锁归档，不明锁保守拒绝，恢复/开库之前获取锁。保护当前正式运行服务。
- 不更改 SQLite schema 1，不需要数据库迁移；仍建立升级前可恢复备份。所有破坏性恢复测试仅在临时库执行。
- 构建、类型检查、自动测试、Windows 启动和真实浏览器执行；无 API Key 则模拟接口隔离测试并明确外部 API 未验证。Git 不含个人数据/附件/备份/密钥，更新交接、测试、架构和配置文档。

实现与限制见 AI.md，实际证据见 TESTING.md；复工先读 HANDOFF.md，不自动执行 ROADMAP。
