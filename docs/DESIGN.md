# V1.6 知识助手体验

侧栏独立知识助手，问答/结构/跨范围同一分区组件。先展示本地证据和操作规模，用户选择后才生成；不可用AI保留手工功能。知识目录提供结构快捷入口，面包屑与选中导航明确。

结构入口先显示本地问题候选，名称筛选可找其他对象；生成后仅显示所选证据，避免大量未选卡片把审核挤到页面末尾。AiReviewItem复用B的原/新状态、原因、直接影响与内容/关系说明，编辑、部分采用、差异预览及明确确认。合并第二确认，草稿冲突不强行覆盖；历史入口安全恢复。

问答用已有资料（仍需核对）/模型推断/缺失证据分别展示，引用按钮进入真正站内对象。范围整合只本地展开，选择少量资料并另建或追加章节。取消生成、离开未保存确认、加载/错误与粗估费用保持原视觉；390px/深浅主题实际Edge截图复核，0pageerror。

# V1.5-B 阅读与整理

目录把页面当阅读入口，独立知识可通过“查看所有知识点”与全文搜索找到。隐藏卡片不等于自动归属；页面为空时明确给出人工收纳入口，旧显式parent可审核采用。

页面从标题、概览、原富文本开始，接大纲+章节两列，长正文默认折叠并按需读入。来源、日期、状态/优先级放可展开详情；大纲点击展开定位，不把技术信息当阅读正文。9点合成阅读、1440桌面、390窄屏及深色实际截图复核；窄屏大纲变独立可滚动区，不横向溢出。

整理模式提供显式选择、收纳、改父级、上下排序、编辑/归档及主动AI整合。收纳列表清楚标所属页/独立，提供当前页独立点批选，不由同目录猜归属。知识历史通过预览放入编辑器，最终保存仍由用户确认。

AI采用独立审核弹窗：输入规模/费用粗估/主动费用确认→候选章节、六种关系及原文依据、顺序、待验证→编辑、部分选择或拒绝。新章节标记待验证AI推断，原章节始终保留；缓存方案标注不调用。导入先展示实际层级，再在每条中编辑父级，不增加第二套目录系统。

## V1.3 专题与分享解析

专题侧栏进入整页：标题/介绍/数量/时间 → 富文本总结 → 资源卡片，延续中性背景、绿色强调和领域默认封面。选择资源、站内详情、外链、添加/移除明确，空专题可编写总结或添加资源。原组合筛选保留，不新增第二套分类。

总结复用现有工具栏/图片，编辑区尾部保存/取消及独立草稿反馈；离开未保存确认、刷新草稿恢复。过期手工草稿恢复需确认后继续编辑，旧 AI 草稿不得覆盖新版本。历史面板预览与确认恢复，先保留当前版。

AI 预览明确尚未采用，编辑标题/段落与〔来源N〕，清单含真实站内/原网址。追加或确认替换先进入编辑器，保存才落正式记录；信息不足、超限、来源失效、取消和网络错误可见。说明明确用户提供文字、未读取视频。生成/上传/保存期间禁用冲突操作。

分享解析保留本次原始文字、多URL选择、候选标题及默认不选的话题，允许拒绝/重解析/修改，已有标题笔记保持，新标签确认。无密钥输入或复杂工作台。真实 Edge 复核桌面、深色与390px窄屏。

V1.1 使用暖中性灰背景、白色内容层和绿色强调色，深色主题沿用相同信息层级。中文系统字体优先，无外部字体或占位图请求。桌面侧栏固定，内容区留白，3/4 列规则卡片；较窄屏 2 列，小屏 1 列。

网格封面 2:1，标题/简介各两行，统一高度；默认封面由领域名称计算连续 HSL 色调和不同 Lucide 图标，原创笔记用文档图标，增加类型提示。列表采用小封面和横向内容行。卡片底部提供置顶、编辑与外链。

新增/编辑和详情使用弹窗，网址优先、输入分组、最近分类、多选标签、工具栏、固定标题和保存栏。弹窗锁定背景滚动、约束焦点、Escape 关闭；未保存关闭先确认保留草稿。格式按钮和选择控件显示状态；链接使用表单面板；读取/保存期间锁定编辑。加载骨架、空结果、错误块、成功提醒和草稿保存状态独立呈现。

领域导航、标签和专题筛选、视图与排序处于明确分组中；当前筛选可取消。批量模式明确说明选择当前页，加载/操作期间禁用控件。详情正文最大宽度 680px、字号与段落间距适合阅读，长内容在弹窗内部滚动，不截断正文。

深浅色主题遵循相同内容层级；自适应导航和表单保证窄屏不横向溢出。图片内容 object-fit cover；详情正文保持自然比例。
