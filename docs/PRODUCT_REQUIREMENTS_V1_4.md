# V1.4 工具导航库与设置分区

用户本轮范围取代旧 ROADMAP 中同版本号的网页抓取候选；最终停在 V1.4，不执行后续版本。

- 独立工具库入口，分类导航与紧凑图标卡片，备注按需展开，延续中性/绿色、深色与窄屏。
- 名称、可选 HTTP/HTTPS 网址、用途、图标、工具类型（网站/在线/AI/桌面/自制/其他）、多领域/标签/专题、个人富文本备注。添加、编辑、确认删除、搜索、筛选、排序、置顶、列表与原有批量管理。
- 全站搜索包含工具备注；普通笔记列表不混入工具。复用 entries 的稳定 UUID、assets 和原多对多关系，不创建重复资源库，不实现问答或软件执行。
- 设置四个分区：分类管理、AI 配置、备份与草稿、网站启停；分类快捷入口定向到领域/标签/专题表单，重置滚动并聚焦。隐藏分区不进入焦点循环，密钥未保存关闭保护继续生效。
- schema2 → 3 只 ALTER 新增工具元数据字段及索引，旧行/关系/专题无损；每个迁移步骤前保存并校验可恢复 ZIP，未知 schema 安全拒绝。兼容旧 schema1/2 和新 schema3 备份。
- 新增工具与新增收藏草稿分开；正文沿用 HTML 白名单、图片和 1 MB 限额，分类与资产 ID 校验不变。
- 保留 Windows DPAPI、安全本地 API、两种 Provider、人工审核、用量与本地实例锁；工具页不自动调用模型，不访问来源网页，不读取真实密钥或发付费请求。
- 验收以 TESTING/HANDOFF 的真实构建、隔离自动化、Edge、Windows 进程启停及 ZIP 恢复记录为准。整机重启和真实云端验证不能由模拟测试代替。
