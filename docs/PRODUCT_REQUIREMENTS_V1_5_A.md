# V1.5-A：知识组织与人工审核导入

开工基线 48461d055b8ddc02933de355a41ae84f23bc07b9，V1.4 已交付且工作区干净。新授权仅 A 阶段，取代 AGENTS 原停在 V1.4 的范围；不执行 B 阶段或网页抓取。

## 实现方案

- 原 entries 继续持有 UUID、富文本/纯文本索引、分类、附件及专题多对多；新知识元数据以一对一扩展，不将旧收藏或工具自动变为知识点。
- 新目录是可手动组织的知识树（最多 8 层），与领域/标签/专题各司其职；非空目录不直接删除。收集记录、混合知识页面、独立知识点共用原 entries。混合页可引用已有知识/网址/工具/笔记，不复制资源。
- 记录支持目录、手动上下移动、0～3 优先级、收集/草稿/待验证/人工确认/归档、来源资料与待验证问题；来源报告、AI 推断、源资料称为用户判断独立标注，人工确认必须用户操作。
- JSON knowledge-exchange v1 有机器 Schema，来源日期为空表示未知；不把导入时间当作观点形成日期。原始包、摘要哈希、来源摘录/文字引用保留并可查看；URL 仅用户提供，未抓取或验证。
- 导入先解析、预览、逐条修改/选择/拒绝；目录和领域/标签/专题创建建议默认不选。标题不是唯一键；重复包按哈希检测，须明确另存或取消；相近内容仅本地候选，无自动合并/删除。
- 选中知识、已明确确认的新分类/目录、来源和关系在单事务落地；来源 ID/引用摘录须来自当前包，关系只能指向本轮选中记录或明确选择的现有 ID。所有关系候选默认未确认。
- Markdown/纯文本原样保留为单条收集记录，正文作为转义文本，不推断多条知识或日期。
- 512 KiB 输入、最多 100 条/100 来源/100 目录/200 关系、嵌套深度 8、严格字段/日期/URL/HTML 校验；不读取 ChatGPT 历史、不进行付费 API 调用。导入模块独立于 UI，使用受保护同源/session API 和短期预览令牌。
- schema4 只追加知识表，顺序迁移前 ZIP 完整校验，旧 schema1/2/3 向前恢复；安全凭据、锁、用量与旧草稿不改变。

## 阶段边界

A：目录/知识对象/手动组织/来源追溯/最小 JSON 审核导入/导出提示词及验证。B：长对话自动拆分、模型判断重复/冲突、跨来源整合与费用估算，复用 A 对象；本轮不实现、不自动调用模型。现有网站内 AI 仍处理用户主动选择的小规模文字，ChatGPT 另行人工整理后通过本格式导入；订阅不等于 API 额度。
